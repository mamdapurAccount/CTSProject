Unix Operating System :


Unix is a multi-user, multitasking operating system that manages computer hardware and software resources efficiently. It allows multiple users to work simultaneously and run many programs at the same time.

Multi User Operating system, Multi Task Operating system


Multiuser
Multitasking
Portable
Secure
Reliable
Command-based
File-oriented

 It consists of three main parts:

Kernel – Core of the system (manages memory, processes, devices)
Shell – Interface between user and kernel (command interpreter)
File System – Organizes and stores data in files and directories

Kernel manages system resources like CPU, memory, files, and devices, and enables communication between hardware and software.
It Manages Process Management, Memory Management, File Management , Device Management


User ----> Shell ( Command Interpretor) ----> Kernel ( Core part of OS )---> Hardware ( CPU,Memory,Device, Disk)


 Important Directories

    File Types in Unix

 1. / (root)
 Starting point of everything

 2. /bin
    System commands (executables)
Examples:
Shells, cp, mv, shShow more lines

 3. /home
 User directories
Example:
/home/manoj


 4. /etc
 Configuration files

 5. /tmp
      Temporary files

 6. /dev
    Device files (keyboard, disk, etc.)

 7. /usr
  User programs and applications

 Job Control

Manage background and foreground processes

jobs              # List running jobs

  Press Ctrl Z ( Suspend the job not Terminated )

bg %1             # Resume job in background without blocking the terminal
kill %1           # Stop a job
